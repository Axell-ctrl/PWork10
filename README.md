Практическая работа №10.

Задание: Разработать программу для работы с квадратной матрицей случайных чисел в диапазоне \([a, b]\) с возможностью выбора размерности пользователем (3 или 4). Реализовать алгоритм модификации матрицы в зависимости от четности количества столбцов: для нечетной размерности поменять местами первый и средний столбцы, для четной — два средних столбца с первым и последним соответственно. Обеспечить цветовое выделение измененных элементов при выводе результирующей матрицы в консоль.
